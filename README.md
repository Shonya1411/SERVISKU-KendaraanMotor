# SERVISKU

Aplikasi contoh pemesanan servis motor (tugas Interaksi Manusia dan Komputer).
Dibuat dengan HTML, CSS, dan JavaScript biasa, tanpa proses build.

## Cara menayangkan lewat GitHub Pages

1. Buat repository publik baru di GitHub, misalnya `servisku`.
2. Klik **Add file > Upload files**, tarik semua file di folder ini, lalu **Commit changes**.
3. Buka **Settings > Pages**. Di bagian Build and deployment, pilih Source: **Deploy from a branch**, Branch: **main**, folder **/ (root)**, lalu Save.
4. Tunggu 1 sampai 2 menit. Link aplikasi: `https://USERNAME.github.io/servisku/`

## Pasang di HP

- Android (Chrome): menu titik tiga > **Instal aplikasi** atau **Tambahkan ke layar utama**.
- iPhone (Safari): tombol Bagikan > **Tambah ke Layar Utama**.
